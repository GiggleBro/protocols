概述

Overview

我们非常重视您的隐私与数据安全。本隐私政策说明 印章模拟器（以下简称“本应用”或“我们”）在使用过程中如何使用设备权限、处理相关数据，以及您享有的权利。

We take your privacy and data security very seriously. This Privacy Policy explains how Seal Maker (hereinafter referred to as "this App" or "we") uses device permissions, processes related data, and the rights you enjoy during use.

我们使用的设备权限

Device Permissions We Use

本应用仅在实现核心功能所必需的情况下，使用以下系统权限：

This App only uses the following system permissions when necessary to implement core functions:

  • 文件访问（Files）Files Access：用于读取用户选择进行盖章的图片和PDF文件，以及保存盖章后的文件。Used to read images and PDF files selected by users for stamping, and to save stamped files.
  • 相册访问（Photos）Photos Access：用于读取用户选择进行盖章的图片，以及将盖章后的图片保存回用户相册。Used to read images selected by users for stamping and save stamped images back to the user's photo album.
  • 网络访问（Internet）Internet Access：仅用于应用内购买（订阅会员）的支付请求、订单验证及购买状态恢复。Only used for in-app purchase (subscription membership) payment requests, order verification, and purchase status restoration.

除上述权限外，本应用不会请求定位、通讯录、蓝牙、麦克风等与核心功能无关的系统权限。

In addition to the above permissions, this App will not request system permissions unrelated to core functions such as location, contacts, Bluetooth, or microphone.

文件与图片数据说明

File and Image Data Description

当您选择使用本应用的盖章功能时，图片和PDF数据仅用于本地盖章处理。

When you choose to use the stamping function of this App, image and PDF data are only used for local stamping processing.

所有处理的文件内容：

All processed file content:

  • 仅在您的设备本地进行处理；
  • Processed only locally on your device;
  • 不会被上传、分析或共享至任何服务器；
  • Not uploaded, analyzed, or shared to any server;
  • 盖章后的文件仅保存在应用内部目录或您指定的位置。
  • Stamped files are only saved in the app's internal directory or the location you specify.

印章数据说明

Stamp Data Description

您创建或导入的印章数据（图片、文字、设置等）：

Stamp data you create or import (images, text, settings, etc.):

  • 仅保存在您的设备本地；
  • Saved only locally on your device;
  • 不会被上传至任何服务器；
  • Not uploaded to any server;
  • 可通过应用内设置进行管理和删除。
  • Can be managed and deleted through in-app settings.

应用内购买与支付说明

In-App Purchase and Payment Description

本应用提供应用内购买服务，包括印章会员订阅等虚拟权益。所有支付流程均通过 Apple 官方的 App Store 应用内购买体系（StoreKit）完成。

This App provides in-app purchase services, including virtual benefits such as stamp membership subscriptions. All payment processes are completed through Apple's official App Store In-App Purchase system (StoreKit).

我们不会获取、存储或处理您的支付信息（如银行卡号、Apple ID 密码等）。购买结果仅用于在本地判断会员状态。

We do not collect, store, or process your payment information (such as bank card numbers, Apple ID passwords, etc.). Purchase results are only used to determine membership status locally.

数据传输与网络使用

Data Transmission and Network Usage

本应用的核心功能（图片盖章、PDF盖章、印章管理）均在设备本地完成，不依赖网络。

The core functions of this App (image stamping, PDF stamping, stamp management) are all completed locally on the device and do not rely on the network.

应用仅在以下场景下使用网络：

The App only uses the network in the following scenarios:

  • 发起应用内购买请求；
  • Initiating in-app purchase requests;
  • 向 Apple 验证订阅或购买状态；
  • Verifying subscription or purchase status with Apple;
  • 恢复已购买的订阅权益。
  • Restoring purchased subscription benefits.

在任何情况下，本应用不会上传或存储您的原始文件、盖章后的文件或印章数据。

Under no circumstances will this App upload or store your original files, stamped files, or stamp data.

数据存储与保留

Data Storage and Retention

本应用不在服务器端保存任何用户生成内容。所有文件和印章数据均由您的设备本地管理。

This App does not save any user-generated content on the server side. All files and stamp data are managed locally on your device.

若您删除本应用，应用不会保留任何与您相关的个人数据或媒体内容。

If you delete this App, no personal data or media content related to you will be retained.

与应用内购买相关的网络通信仅发生在您的设备与 Apple 官方服务器之间。
