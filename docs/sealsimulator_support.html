常见问题解答

FAQ

Q: 盖章后的文件保存在哪里？

Q: Where are stamped files saved?

A: 盖章后的文件保存在应用内部文件列表中，您可以在首页的文件列表中查看和管理。

A: Stamped files are saved in the app's internal file list. You can view and manage them in the home page file list.

Q: 如何获取更多功能？

Q: How to get more features?

A: 订阅印章会员即可解锁全部高级功能，包括自动覆盖保存、印章透明通道设置等。

A: Subscribe to Stamp Membership to unlock all premium features, including auto-overwrite save and stamp alpha channel settings.

Q: 印章可以导出吗？

Q: Can stamps be exported?

A: 是的，您可以在印章列表中选择印章并导出到相册。

A: Yes, you can select stamps in the stamp list and export them to your photo album.

Q: 如何取消订阅？

Q: How to cancel subscription?

A: 您可以在 iOS 系统设置 → Apple ID → 订阅中找到印章模拟器并取消订阅。

A: You can find Seal Maker in iOS Settings → Apple ID → Subscriptions and cancel the subscription.

遇到问题？先试试这些步骤

Having issues? Try these steps first

  • 确认应用已获得「文件」访问权限：iOS 设置 → 隐私与安全 → 文件与文件夹 → 找到 印章模拟器 并允许访问。
  • Ensure the app has "Files" access: iOS Settings → Privacy & Security → Files and Folders → Find Seal Maker and allow access.
  • 确认应用已获得「相册」访问权限：iOS 设置 → 隐私与安全 → 照片 → 找到 印章模拟器 并允许“读取与写入”。
  • Ensure the app has "Photos" access: iOS Settings → Privacy & Security → Photos → Find Seal Maker and allow "Read and Write".
  • 尝试重启应用或设备后再次尝试。
  • Try restarting the app or device and try again.
  • 确保您的设备已更新到最新版本的 iOS。
  • Ensure your device is updated to the latest iOS version.
